# Бизнес-правила ядра оркестрации

## BR-01. Выбор действия при сбое

| Тип ситуации | Повтор допустим | Лимит повторов исчерпан | Есть допустимая замена | Результат обязателен | Меняются подтверждённые условия | Действие |
|---|---|---|---|---|---|---|
| Некорректные параметры подзаказа | Нет | - | - | Любое | Нет | Запросить уточнение параметров |
| Временная техническая ошибка | Да | Нет | Любое | Любое | Нет | Повторить текущий подзаказ |
| Тайм-аут поставщика | Да | Нет | Любое | Любое | Нет | Повторить после заданного интервала |
| Повторы исчерпаны или ошибка постоянная | Нет | Да | Да | Да | Нет | Создать замещающий подзаказ |
| Доступна замена, но меняются цена, срок или характеристики | Нет | Да | Да | Да | Да | Запросить повторное подтверждение пользователя |
| Замены нет | Нет | Да | Нет | Да | - | Передать решение пользователю или оператору |
| Необязательная позиция не исполнена | Нет | Любое | Нет | Нет | Нет | Продолжить без позиции и зафиксировать отклонение |
| Допустим неполный результат | Нет | Да | Нет | Да | Нет | Предложить принять частичный результат |
| Частичный результат отклонён | Нет | Да | Нет | Да | - | Завершить заказ как «Не исполнен» |


## BR-02. Выбор поставщика

| Критерий | Вес для макета | Правило оценки |
|---|---:|---|
| Соответствие продукту и параметрам | Обязательный фильтр | Несоответствующий поставщик исключается |
| Возможность выполнить заказ в срок | 30% | Чем меньше ожидаемый срок, тем выше оценка |
| Стоимость | 25% | Чем ниже стоимость при равных условиях, тем выше оценка |
| Надёжность | 20% | Учитывается доля успешных исполнений за согласованный период |
| Полнота покрытия области интереса | 15% | Предпочтение максимальному допустимому покрытию |
| Приоритетный договор или лимит | 10% | Учитываются доступный лимит и договорные предпочтения |

| Условие | Решение |
|---|---|
| После фильтра не осталось поставщиков | Заказ не размещать; запросить изменение параметров |
| Остался один поставщик | Выбрать его и сохранить причины выбора |
| Несколько поставщиков имеют разные оценки | Выбрать поставщика с максимальным итоговым баллом |
| Итоговые оценки равны | Выбрать поставщика с меньшим сроком, затем с меньшей стоимостью, затем зарегистрированного первым в справочнике |


## BR-03. Приёмка результата

| Целостность | Формат | Метаданные | Объём | Условия подзаказа | Решение |
|---|---|---|---|---|---|
| Пройдена | Соответствует | Полные | Соответствует | Соблюдены | Принять результат |
| Пройдена | Соответствует | Неполные, исправимые | Соответствует | Соблюдены | Запросить исправление метаданных |
| Пройдена | Допустимо преобразовать | Полные | Соответствует | Соблюдены | Преобразовать и повторно проверить |
| Не пройдена | Любой | Любые | Любой | Любые | Отклонить результат |
| Пройдена | Соответствует | Полные | Частичный | Частичное исполнение разрешено | Принять доступный объём и зафиксировать отклонение |
| Пройдена | Соответствует | Полные | Частичный | Требуется полный объём | Запустить коррекцию исполнения |
